`v0.2.10` bounds storage growth with compressed raw-log segments and smaller
search indexes, and routes prior-work requests to LCM before curated memory.

## Changes

- ([#60](https://github.com/Team-Volt/codex-lcm/pull/60)) Restore the full package layout by removing the package-level `.npmignore`.
- ([#61](https://github.com/Team-Volt/codex-lcm/pull/61)) Route requests for prior-session evidence to `lcm-recall` before curated memory, and make the boundary between those sources explicit.
- ([#62](https://github.com/Team-Volt/codex-lcm/pull/62)) Rotate the authoritative raw log into compressed 64 MiB segments, replace duplicate SQLite payloads with verified byte locators, migrate existing stores with resumable crash-safe state, add optional age-based retention, report migration state through diagnostics, and skip unsupported directory syncs on Windows.
- ([#63](https://github.com/Team-Volt/codex-lcm/pull/63)) Announce that [agent-lcm](https://github.com/Team-Volt/agent-lcm) will replace this repository.
- ([#64](https://github.com/Team-Volt/codex-lcm/pull/64)) Rebuild event and summary FTS tables as contentless-delete indexes keyed by canonical row IDs, migrate them in one transaction, and reclaim space in detached maintenance without changing ranked results.

## Upgrade to v0.2.10

Restart Codex Desktop or open a fresh Codex CLI/TUI session after upgrading so
the refreshed plugin cache, MCP server, hooks, and skill are loaded.

For an existing GitHub marketplace install:

```sh
codex plugin marketplace remove codex-lcm
codex plugin marketplace add Team-Volt/codex-lcm --ref v0.2.10
codex plugin add codex-lcm@codex-lcm
```

For a local checkout install:

```sh
git -C /path/to/codex-lcm fetch --tags origin
git -C /path/to/codex-lcm checkout v0.2.10
codex plugin add codex-lcm@codex-lcm
```
