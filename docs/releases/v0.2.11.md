`v0.2.11` improves capture and storage integrity, redaction, session import
reporting, and Codex hook output validation.

## Changes

- ([#66](https://github.com/Team-Volt/codex-lcm/pull/66)) Redact GitHub OAuth and app tokens, preserve streamed UTF-8, and record explicit depth limits for deeply nested hook input. Keep recent summary roots and source lineage in bounded graphs, verify archived segment checksums before returning evidence, and invalidate cached reads when files change. Batch raw appends and fsyncs, reuse raw-log and stats scans, schedule retention only when archives expire, and exclude local evidence from package tarballs.
- ([#67](https://github.com/Team-Volt/codex-lcm/pull/67)) Classify credential keys by value shape so numeric metrics and boolean metadata survive redaction while passwords, API keys, and other always-secret fields remain protected.
- ([#68](https://github.com/Team-Volt/codex-lcm/pull/68)) Classify imported session files as UUID rollouts, current Codex records, subagent transcripts, or forked rollouts with lineage. Report source-kind counts and unclassified files while keeping import progress responsive.
- ([#69](https://github.com/Team-Volt/codex-lcm/pull/69)) Validate hook stdout against a shared Codex host profile, keep PostCompact output empty, and reject output formats unsupported by the hook event.
- ([#70](https://github.com/Team-Volt/codex-lcm/pull/70)) Remove the README announcement that Codex LCM will be deprecated and replaced by agent-lcm.

## Upgrade to v0.2.11

Restart Codex Desktop or open a fresh Codex CLI/TUI session after upgrading so
the refreshed plugin cache, MCP server, hooks, and skill are loaded.

For an existing GitHub marketplace install:

```sh
codex plugin marketplace remove codex-lcm
codex plugin marketplace add Team-Volt/codex-lcm --ref v0.2.11
codex plugin add codex-lcm@codex-lcm
```

For a local checkout install:

```sh
git -C /path/to/codex-lcm fetch --tags origin
git -C /path/to/codex-lcm checkout v0.2.11
codex plugin add codex-lcm@codex-lcm
```
